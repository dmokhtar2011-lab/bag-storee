# رفع متجر حكاية على GitHub Pages

## ملفات الموقع

ارفعي هذه الملفات الأربعة معًا في جذر المستودع:

- `index.html`
- `checkout.html`
- `style.css`
- `store.js`

## النشر مجانًا

1. أنشئي مستودعًا جديدًا على GitHub، واجعليه **Public** (GitHub Pages متاح مجانًا للمستودعات العامة).
2. افتحي المستودع، ثم اختاري **Add file → Upload files**.
3. فكّي ضغط حزمة الموقع، واسحبي الملفات الأربعة إلى الصفحة، ثم اضغطي **Commit changes**.
4. من **Settings → Pages** اختاري **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغطي **Save**.
5. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

## مهم بخصوص الطلبات

GitHub Pages يستضيف صفحات ثابتة فقط. صندوق الطلبات الموجود في النسخة الحالية يحفظ الطلبات في متصفح الزائر نفسه؛ لذلك لن تظهر طلبات العملاء عندك. يلزم ربط قاعدة بيانات وخدمة خلفية مجانية لكي تُحفظ الطلبات مركزيًا. لا تضعي بيانات دخول أو مفاتيح سرية في ملفات الموقع العامة.
